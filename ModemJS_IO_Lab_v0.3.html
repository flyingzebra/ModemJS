6. Channel impairment emulator

Applies controlled disturbances to the transmitted test signal before it reaches the selected speaker. This makes repeatable receiver-side robustness tests possible.

Clean
Amplitude / level
Echo / multipath
Phase / timing

Implemented as an equivalent sub-cycle time delay at the reference frequency. This creates a frequency-dependent phase slope, as a real propagation/timing error would.

Additive noise

Broadband pseudo-random noise is mixed into the transmitted waveform.

Band limiting
Non-linearity

Useful for testing overdriven speakers, microphone front ends, AGC-like compression effects, and FSK harmonic contamination.

8. Link study and export

Give both laptops the same experiment ID. Save a report on each side; TX and RX are independent because the audio link has no packet exchange yet. Reports contain configuration, timestamped TX events, RX time series and statistical summaries—not raw microphone audio.
